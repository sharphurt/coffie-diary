# Матрица приёмки — итерация 0.1

Проверено 13 ноября 2026. V1 не завершена. PASS означает проверенное поведение указанной итерации, а не готовность всего продукта. FAIL — требование пока не закрыто; BLOCKED — указан конкретный внешний блокер.
